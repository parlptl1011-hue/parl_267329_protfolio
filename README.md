# My Personal Portfolio Website

## About the Project
This is my personal portfolio website created using HTML, CSS, and JavaScript. It provides a simple and attractive way to introduce myself and showcase my skills, projects, and contact information.

## Features
- Home / About Me section
- Skills section
- Projects section
- Contact information
- Simple and user-friendly design
- Responsive layout

## Technologies Used
- HTML – To create the structure of the website.
- CSS – To style and design the website.
- JavaScript – To add interactive features.

1. Download or clone this repository.

4. Explore my portfolio website.
